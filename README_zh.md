# 猎人游戏：王冠易主

一个基于猎人游戏的变种数据包，目前还是半成品  

当逃脱者死亡后，游戏不会结束，而是杀死逃脱者的猎人成为新的逃脱者，死亡的逃脱者复活后以猎人的身份继续游戏  
末影龙死亡时，此时的逃脱者获得胜利。

适用于 Minecraft Java 版 26.3。

## 开始游戏

在聊天栏或命令方块中执行：

- `/function mhc:start`：随机选择一名生存模式玩家作为逃脱者；其他生存模式玩家成为猎人。
- `/function mhc:start_player {player:"玩家名"}`：指定生存模式逃脱者。
- `/function mhc:start_debug`：随机选择一名非旁观模式玩家作为逃脱者；其他非旁观模式玩家成为猎人。
- `/function mhc:start_debug_player {player:"玩家名"}`：调试模式下指定逃脱者。
- `/function mhc:stop`：停止游戏并清除在线玩家的角色标记。

指定玩家的函数使用 Minecraft 函数宏参数，玩家名应写在 `{player:"..."}` 中。
原版函数宏参数不能同时兼容“无参数随机开始”和“带玩家参数开始”，因此指定玩家时使用单独的 `*_player` 函数。
