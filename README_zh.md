# 猎人游戏：王冠易主

[English](README.md)

《Manhunt: Crownshift》是适用于 Minecraft Java 版 26.3 的多人追猎数据包。猎人追捕逃脱者；逃脱者死亡后，造成击杀的猎人接替成为逃脱者，死亡的逃脱者复活后成为猎人。如果逃脱者死于非玩家伤害，则由最后一位伤害过他的玩家接替；若没有玩家伤害过他，则随机选择一名猎人接替。末影龙死亡时，当前逃脱者获胜。

数据包会记录玩家在各维度的最后位置。逃脱者穿过下界传送门时，聊天栏会提示其在原维度最后出现的位置。逃脱者掉线后有五分钟重新连接；超时后游戏会选择新的逃脱者。

## 安装

1. 将数据包文件夹 `manhunt-crownshift` 复制到目标存档的 `datapacks` 文件夹中。
2. 进入或重新打开存档。若存档已经打开，在聊天栏执行 `/reload`。

本数据包适用于 Minecraft Java 版 26.3。

## 开始与停止游戏

在聊天栏或命令方块中执行：

- `/function mhc:start`：开始游戏，随机选择一名生存模式玩家作为逃脱者。
- `/function mhc:start_player {player:"玩家名"}`：指定一名生存模式玩家作为逃脱者并开始游戏。
- `/function mhc:stop`：停止游戏。

将 `玩家名` 替换为准确的游戏内玩家名。
